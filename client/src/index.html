Connect to your server

Enter the secure web address for the Unifierr server running on your NAS or computer.

Use the full address, including https://. You can include a port or path if your server uses one.

Before you connect

  • Your Unifierr server must be running and reachable.
  • For a private NAS, connect this device to the same Tailscale network first.
  • The server address must use HTTPS with a certificate this device trusts.
Your last server address is saved on this device only.
