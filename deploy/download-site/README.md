# Unifierr downloads

This is the static page hosted at `unifierr.skillsgeek.com`. Download files live in the server's `/downloads/` directory and are deployed separately from Git so release binaries and the server image are not committed to source control.

The client downloads are preview builds from the private `client-v0.1.2` release, copied to the public download host. Windows/macOS are unsigned and Android is an ARM64 debug APK. The Synology server archive is a fresh-install preview for `linux/amd64`; its guide describes its network and security requirements.
